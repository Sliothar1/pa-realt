# Accessibility gates (PA Réalt)

CI job `a11y` (.github/workflows/ci.yml) runs on every push and PR:

| check | tool | fails CI? |
|---|---|---|
| WCAG AA contrast of each text/accent token on each surface, night and dawn | `scripts/a11y_check.py a11y.json` (C1) | yes |
| skip link is the first link and its target exists (all pages) | C2 + browser A2 (Tab, Enter) | yes |
| `prefers-reduced-motion` override exists; no infinite animation runs under reduce | C3 + A3 | yes (JS smooth scroll in js/ask.js: warning) |
| `<html lang="en">` | C4 | yes |
| Irish text carries `lang="ga"` | C5 heuristic (fadas, lenition, eclipsis; allowlist in a11y.json) | warning only |
| non-map list equivalent for each map page | C6: index.html → list.html (`scripts/build_list.py`) | warning if missing |
| axe-core WCAG 2.0/2.1 A+AA, every page, both themes | `scripts/a11y_axe.py` (A1) | yes |

Manual, before a release (not automatable here): keyboard-only walk of the map (zoom, chips,
search combobox, card, Esc closes menus, focus visible); a screen reader pass (VoiceOver or NVDA)
on index, results and list; 200% zoom and 320 px width.

Known warnings (11 Oct 2026): js/ask.js calls `scrollIntoView({behavior:'smooth'})` and app.js
`flyTo` without checking reduced motion in some paths; list.html shows Irish-form townland names
from the English townland field without `lang="ga"` (source data).
